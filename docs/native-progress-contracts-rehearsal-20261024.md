## Contracts repaired

1. **Generation progress and diagnostics.** The selected server uses compact Guidance decoding; all captured whitespace-loop prefixes retain their content while padding becomes inadmissible. Explicit vLLM transport reads bounded SSE frames, reconstructs JSON across split frames, recognizes the protocol terminator without waiting for connection closure, and retains final usage independently of output validity. Interrupted calls expose bounded request ID/timing/formatting diagnostics without guessing usage or logging partial text. Other compatible/Ollama routes retain their existing behavior.
2. **Native envelopes and reference namespaces.** Stable output contracts are separate from observation-bound generation schemas. Shared feedback and accounted recovery enforce both. Refreshed revisions may change; native memory bounds cannot be waived. Simulation narrowing recognizes action/proposal roles and does not rewrite every matching field name or literal data. V2 memory advertises only delivered original evidence IDs. Remaining native decode rejection receives bounded correction when that policy is enabled.
3. **Request-scoped correction.** Legacy active feedback is tied to the simulation request and is cleared when satisfied; recorded history remains. A rejected numerical choice receives a generation refinement containing the alternatives that satisfy the explicit integer objective. This constrains a retry; the host does not substitute or execute an answer. First-pass model mistakes remain measured. Native feedback and legacy correction keep the original three-call limits.
4. **Shared resource admission.** An additive migration supports optional token-weighted leases alongside slot counts. Exact tokenizer demand is measured outside transactions; reserved output and the selected cache allocation rounding are charged. Both legacy/native paths use the same queue. Oversized/aborted preparation does not invoke a model; existing unknown token demand is conservative. Compute-usage uncertainty remains independent of the transient capacity lease.
5. **Durable requests and timing.** Each synthetic request persists until its own receipt. Later publication does not overwrite unfinished requests or invalidate an unchanged active request merely by appending future work. Request completion, receipt and peer notification are atomic and idempotent. Thirty rounds publish on fixed minute boundaries independently of other kingdoms. The 30-minute offered-load window has a separate bounded 90-second drain for admitted work; no new workload is offered during drain.
6. **Outcome reporting.** The harness reads authoritative turn state/code and unknown usage after controller return. Internal legacy errors can no longer appear as successful RETURNED turns. Attempts, dispatched invocations, reported/unknown/not-dispatched usage, task notifications and receipt-based request outcomes are separate. Late peer notifications are retained and intake uses sequence cursors rather than dropping notifications from older rounds.

The scripted provider now validates its own responses against the actual generation schema. Its examples include required cognition and choose the correct native read/final branch, so fake-provider acceptance cannot silently depend on invalid example shapes.

No repair is activated by that investigation.

Exact physical-cache headroom is therefore not certified by the aggregate token guard. No preemption causes a failed request here, but this result does **not** establish a zero-preemption or hard latency guarantee. Further conservative headroom calibration is separate from this frozen measurement; no mid-run tuning was done.
