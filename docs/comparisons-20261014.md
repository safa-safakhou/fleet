## Feature

The portable versioned template specifies a shared LLM, reasoning/thinking, allowance and interval, with paired identical strategy preferences. The two modes use the existing engine and account-owned cognition pipeline. Optional Laya assists recall ordering, with fallback measured separately. Preview/export/import is configuration only. Explicit draft saving is atomic and retry-safe; account connection, permissions, observation and starting each group remain independent reviewed actions.

An additive comparison record links the two draft cohorts and retains the original template/digest. Authenticated origin/CSRF-protected APIs and the console compare actual state, configuration drift, lifetime accounting, committed outcomes and retained consented analysis/recall telemetry. They expose accepted analysis counts separately from duplicate suppression and Laya delivery. No claimed intelligence metric, peer-text publication, host-specific credential import or game-domain dependency was added. See [feature and API instructions](comparisons.md).
