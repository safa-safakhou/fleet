## Temporal fixtures and limits

`DiagnosticEpisodes` uses the real unchanged engines, admission and cognition stores, with purely synthetic game ports and withheld commands. One cohort/account/agent and (modern) binding persists throughout each three-turn episode. Only these owned diagnostic agents receive explicit synthetic turn requests; production schedules/anchors are untouched. Game time advances1000/2000/3000 while deadlines use the real wall clock. Fixtures pause after each turn. No automatic recovery of blocked identities or replay exists.

Both paths receive the same semantic current facts/history and owner goals. Their input formats, evidence representation, retrieval policies and mandatory versus optional review remain different; this is not an isolated causal architecture comparison. The no-evidence control lacks evidence of Maple's reliability; legacy still observes ordinary world state, whereas modern has an empty fact list. The explicit memory control measures elicited capability. Ordinary episodes leave strategy, memory writing and communication optional. Promise/outcome facts are distinct; the resource episode retains the owner's80-iron reserve until game time5000 with100 stock and a later40-iron offer.

For helper arms, original and focused use identical candidate text; compact removes formatting prefixes without adding facts omitted by saved220-character truncation. All48 comparisons are paired, not independent observations. One additional multiple-events pair repeats a story class; only8 representative pairs are sampled. Negative/ambiguous controls distinguish irrelevant sources, absent fulfilment, tied relevant sources and absent exact reserve; a confident unique selection on a tie is unjustified preference, not necessarily a false factual assertion.
