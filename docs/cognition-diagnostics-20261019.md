## Temporal fixtures and limits

`DiagnosticEpisodes` uses the real unchanged engines, admission and cognition stores, with purely synthetic game ports and withheld commands. One cohort/account/agent and (modern) binding persists throughout each three-turn episode. Only these owned diagnostic agents receive explicit synthetic turn requests; production schedules/anchors are untouched. Game time advances1000/2000/3000 while deadlines use the real wall clock. Fixtures pause after each turn. No automatic recovery of blocked identities or replay exists.

Both paths receive the same semantic current facts/history and owner goals. Their input formats, evidence representation, retrieval policies and mandatory versus optional review remain different; this is not an isolated causal architecture comparison. The no-evidence control lacks evidence of Maple's reliability; legacy still observes ordinary world state, whereas modern has an empty fact list. The explicit memory control measures elicited capability. Ordinary episodes leave strategy, memory writing and communication optional. For helper arms, original and focused use identical candidate text; compact removes formatting prefixes without adding facts omitted by saved220-character truncation. All48 comparisons are paired, not independent observations. One additional multiple-events pair repeats a story class; only8 representative pairs are sampled. Negative/ambiguous controls distinguish irrelevant sources, absent fulfilment, tied relevant sources and absent exact reserve; a confident unique selection on a tie is unjustified preference, not necessarily a false factual assertion.

Modern thinking proposed an acceptance message without demonstrating the reserve arithmetic; a message proposal is not a settled trade.

The next dependency-ordered source work should preserve engine choice and optional behavior: expose receipt-backed memory-write status and misleading narration; derive focused missing-fact recall queries; improve candidate diversity/selection so repeated snapshots do not crowd out useful owned outcomes and interpretations; retain original sources and their distinct trust level; add semantic diagnostics for exact constraints and receipt-grounded outcome claims. These are proposed changes, not implemented behavior fixes. Neither compulsory memory writing, compulsory alliances, threshold reduction nor another blind full-matrix rerun is supported by this result. Further real-model testing needs a new source-pinned protocol and explicit budget; the unused allowance is not an automatic continuation. Earlier raw/recovery qualification verdicts remain immutable; useful memory and decision quality remain unqualified.
