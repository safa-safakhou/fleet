The compactor takes object fields in insertion order and reduces breadth globally; it does not preserve decision-relevant sections. The generic instruction to obtain a narrower read is ineffective when candidate IDs needed to resolve a candidate were themselves removed. Decision-support cannot be assessed as unsuccessful arithmetic: the controller withheld its results from the model.

Guide checkpoints likewise often contain only six header fields after becoming older entries.
