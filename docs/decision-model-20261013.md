Founder requested an open-source decision model hosted on this Mac alongside the LLM, initially mentioning a possible five-account comparison. The founder then explicitly narrowed the assignment: **implement this feature only; do not work on a comparison yet**. Codex implemented and verified the optional capability without delegation. This report records source acceptance, not a rollout or real-game improvement claim.

## Delivered behavior

Fresh Fleet model configuration now offers **LLM only** or **LLM + Vowpal Wabbit · experimental**, stored as optional `decisionPolicy: "vw-focus-v1"`. Existing absent selections keep their original behavior, and consumed selections remain immutable. Concurrency must be one for this policy. Overview/settings display the mode; authenticated learning status and consented turn steps expose actual selections and feedback.

The pinned open-source **Vowpal Wabbit 9.11.9** CPU contextual bandit selects a strategic focus once per scheduled turn. The LLM, including the installed Nemotron route, receives its bounded advisory focus and decides the actual game read/action/wait within the same input, call and action allowance. There is no extra LLM inference. The optional adapter hook supplies numerical authenticated features; game-specific projection stays in `src/games/pact/decision.ts`. Core scheduling, model service, encrypted learning journal and recovery are game-independent. No PACT gameplay formulas, accounts, grants or mandates are imported or changed.

This is a trained-on-feedback policy, **not a downloaded pretrained PACT agent**. Cold start and all-zero feedback use uniform exploration. Useful feedback trains VW's real action-dependent contextual-bandit learner. The explicit reward observes completed building-level changes, established contact changes and active-contract-count changes at the next eligible scheduled observation. It avoids rewarding raw messages/actions or passive stock accrual. This proxy cannot establish long-term victory, trade value, defensive success or causality; earlier construction and other players can influence it. The LLM can override advice. See [the operator/learning contract](decision-model.md) for the exact reward, feature extraction, 1–45 minute feedback window, censoring and fixed algorithm.

The additive `005_decision_policy.sql` journal encrypts numerical state, selected focus/distribution/propensity and feedback with per-turn vault bindings. Its durable sequence preserves replay order. Eligible feedback is marked learned once; uncertain, interrupted, rejected, unused, old or superseded outcomes are visibly censored. Cohorts never train on another cohort's samples. Python reconstructs its transient model from the latest 2,000 learned samples in the 30-day window, so process restart cannot lose an accepted update or double-learn a retry. A controller retry reuses its persisted choice. Journal rows are purged after 30 days, and backups require the existing matching vault key.

The optional Python service binds only loopback, needs no API/game credentials or GPU, retains no files and logs no request bodies. Requests have a size/feature/history limit and a five-second Fleet timeout. Service absence, mismatch or invalid probabilities causes a visible non-committing turn error before LLM allocation. Late policy responses are fenced when the operator pauses. There is no silent fallback that would mislabel a hybrid turn as a pure LLM decision. Normal game permission/schema/preflight/lease/receipt/uncertainty handling remains authoritative.
