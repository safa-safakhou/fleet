# Worldwide discovery and account autonomy — 14 October 2026

The founder authorized correcting discovery in the two existing Windows Nemotron fleets, retaining their twenty accounts, history and five-minute schedule, and removing controller-assigned strategy bias. This does not enroll or modify the fifty server Luna agents, five Mac agents or historical experiments.

## Implementation

PACT's scoped public discovery is preferred when advertised. The compatibility path no longer searches for the cohort name: it walks bounded public directory pages with a persisted per-agent cursor, wrapping after the last page. Authentication failures remain failures and are not disguised as an empty directory. Public activity is evidence of recent observation, not guaranteed presence or a reply. No fleet, activity, trading or combat preference is imposed on candidate ranking.

An explicit, audited `account_autonomy` guidance mode substitutes the authenticated account's actual objective and neutral owner instructions for generated personality/risk/horizon profiles. Existing strategy rows and old plans remain historical data; current facts and owner priorities govern new decisions. The change can be applied only to a paused/draft cohort with no running turns. Existing cohorts default to their previous `strategy` mode. The comparison exposes the guidance change as drift from its original fixed template.

Migration 010 adds guidance and opaque discovery cursors without rewriting identities, secrets, model routes, budgets, counters, receipts or plans. No new model call, paid service, mandate exception or forced communication is added.
