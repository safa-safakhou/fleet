# Capture matrix v1

Capture is installed by runtime composition, once at native provider and game ports. Existing compatibility runs are explicitly marked `compatibility`; they do not acquire an invented sealed research manifest. Private bytes require current cohort consent. No extra game or model calls enrich evidence.

| Owned path | Capture boundary | Denominator and verification |
| --- | --- | --- |
| Legacy loop and cognition | Engine actual provider invocation; broker GamePort; native transactional observation | Native compute ledger and command resolutions; `research-all-path-capture.test.ts`, byte-identical `architecture-parity.test.ts` |
| Reactive and continuity | ModelAdmission after capacity admission; scoped context/state/continuity services | Native allocations and commands, same five-profile corpus |
| Specialist coordinator/helpers/corrections | Same final ModelAdmission boundary, distinct original allocation IDs; participant ports | Ledger allocations, golden correction and coordinator corpus |
| Skills | Scoped skill services and canonical command journal; no model call for recipes | `skill dispatch and fake worker` test, native platform command row and zero allocations |
| Future Python worker | Language-neutral scope codec and CaptureSession.withScope | In-process fake client round trip and shared native journal fixture; no real worker is implemented before R2 |
| HTTP JSON | HttpModel final JSON body before dispatch and returned protocol body | `research-provider-capture.test.ts`, exact wire comparison over 300 KiB; authentication headers excluded |
| vLLM streaming | Final body including stream options/request ID; decoded SSE packets in delivery order | Provider capture/stream tests; no invented server timing; provider error text explicitly unavailable |
| Codex | Final prompt/schema/flags before process; bounded stdout packets at process close | Existing Linux process suite; macOS skips reported, never treated as acceptance. Stderr/environment/authentication output excluded. Buffered delivery timing is explicit |
| Reads/actions/receipts | GamePort and native intent/receipt transactions | Existing observability/parity tests, ledger reconciliation detects bypass/missing dispatch |

Failures before required dispatch prevent new work. Post-dispatch recording failures flag `capture_failed`, preserve the returned usage/receipt, and fence subsequent dispatches. Transactional private evidence uses an encrypted SQL outbox, materialized after commit. No filesystem or network IO is added inside intent transactions. Revocation/expiry affects private evidence, not accounting/recovery authority.

Synchronous host projections remain synchronous; their resulting prepared model inputs are captured at the final boundary. Provider internals, hidden reasoning and unexposed wire bytes remain unavailable. Exposed JSON/SSE values are retained as JSON, not claimed to be a packet capture. Stream interruption retains prior packets and marks failure; the original transport policy still governs usage certainty.
