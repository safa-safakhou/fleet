# Portable encrypted archives v1

`GET /api/research/runs/:runId/export?snapshotId=UUID` requires the operator session and a recipient-generated 32-byte key in the `x-fleet-export-key` header (64 lowercase hex characters). Save the key separately in an owner-only file. It is independent of the runtime Vault key. Do not place it in URLs or logs. No plaintext-export endpoint or retained export cache exists.

The backpressured stream freezes the authenticated snapshot, follows every event page, preserves original scope/IDs/causal links and streams every referenced retained artifact. Missing sealed manifests on compatibility runs and unavailable/expired payloads remain explicit. A footer records event/artifact/gap/byte counts and a SHA256 record manifest. AES-256-GCM frames are at most 1 MiB plaintext and bind archive ID and frame index. Missing/reordered frames, duplicate events, foreign references, mismatched bytes/digests and incomplete footers fail verification. Structural verification without a key reports `key_required`, never a successful integrity result.

Run offline: `fleet research archive verify --file RUN.fleet --key-file PRIVATE_KEY_FILE`, or `node --import tsx scripts/verify-research-archive.ts --file RUN.fleet --key-file PRIVATE_KEY_FILE`. Exit 0 means verified, 3 key required, 2 invalid. Verification starts no runtime, network connection or game/model call. `writeArchive` publishes an exclusive mode0600 destination only after successful stream completion; failed writes remove their own temporary file. Exports cannot resume: create a new authorized snapshot/archive after interruption. Midstream consent/session revocation aborts delivery and prevents a valid final footer.

The public synthetic portable fixture is `tests/fixtures/research/portable-v1.fleet`; its deliberately public key is 32 repeated bytes `07` (not an operational secret). Write that 64-character hex string to a temporary mode0600 key file, then run the verifier command. `research-archive-verifier.test.ts` also verifies the fixture format and malformed logical records without any database or runtime.

Encryption detects corruption and possession of a key permits decryption; it does not authenticate an external publisher's identity. Transfer archive/key through separately controlled channels. Source ciphertext digests are preserved as evidence references; the export also verifies plaintext byte hashes in its own encrypted record manifest. Private bodies are never printed by the verifier.

Verifier output separates archive `status` from source `coverageStatus`. A structurally verified archive can contain partial/withheld/expired source evidence. The frozen coverage identifies unpublished/partial artifact IDs; `gaps` counts referenced payload gaps. Unpublished bodies without a valid event reference are not promoted into authorized payloads by export.
