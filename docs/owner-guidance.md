# Current owner guidance

AR-F01. `account_autonomy` consumes the authenticated PACT root `world.ambition`, not `world.profile.ambition`. Empty/missing guidance is explicitly absent in model input. Current guidance reaches compact facts, owner instructions and automatic cognition retrieval. An explicit model-selected memory question can refine retrieval within its turn; subsequent turns again start from fresh owner guidance. Strategy mode remains separately selected.

Historical generated strategies, stored notes and subjective plans remain history. They neither replace absent/current owner intent nor change authority. No stored strategy, account, schedule, model, allowance or permission is reset by this correction. PACT's [owned-view contract](../../pact/docs/api/owner-intent.md) owns the field/version and audience semantics.
