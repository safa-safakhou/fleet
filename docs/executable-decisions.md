# Closed executable decisions

AR-F02. Engine generates a closed output schema from reviewed adapter action schemas and the authenticated live read catalog. Each read name binds its exact arguments; action kinds bind their own shapes. Names without a currently selected shape remain available through bounded exact schema lookups, whose admitted names/kinds are also closed. Recent lookup results add only current advertised contracts on a later decision/turn. No arbitrary catch-all action/read is an executable generation branch.

The schema is supplied once via provider transport, rather than repeated as prompt `decisionSchema`, action or read schema lists. Cognition embeds the same closed decision while retaining source-ID constraints independently of game targets; dead legacy definitions are pruned. Ollama keeps its existing `format`; API-compatible requests carry the full JSON-schema response format with `strict: false`, since this Draft-7 contract is not projected into a provider-specific strict subset. Local validation remains required. Actual endpoint/model strict-schema qualification remains separately gated and no live provider is called here.

Compatibility: legacy catalogs without metadata use reviewed names/exact shapes. PACT declared `pact.operation-catalog.v1` metadata must match the operation name/argument contract; unsupported versions fail before model admission. Providers that ignore constraints still face local exact tool/action validation and final server authority. This cannot grant permission or bypass a stale target/stock check. [PACT catalog](https://github.com/safa-safakhou/pact/blob/master/docs/api/agent-catalog.md) owns operation/scope semantics.
