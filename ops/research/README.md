# Fixture-only observation stack

Disabled by default. `npm run test:observability` creates nonce-labeled disposable Collector, Tempo, Prometheus and Grafana containers, network and separate volumes, binds only random loopback ports and uses synthetic events. It verifies trace links, bounded metrics, all dashboard queries, a Chrome-rendered dashboard, exporter failure/restart recovery and sentinel exclusion. Cleanup checks ownership; it never prunes or selects retained services. Failed synthetic fixture logs remain ignored under `.tmp/observability-failed-*` with protected permissions. It uses pinned image digests from the dependency report and disables Grafana plugin preinstallation/updates and analytics.

Docker must be running with the pinned images available locally (`--pull=never`). A disposable Chrome browser is launched using `FLEET_TEST_BROWSER_EXECUTABLE`, the existing macOS Chrome executable when present, or Playwright's managed Chromium on other platforms (`npx playwright install chromium`). No existing profile/session is reused. The screenshot is saved under the plan's ignored verification directory. Browser version is reported; it is not a runtime dependency.

The Compose file is an optional reviewed development recipe; no service starts through application installation. To use it manually, provide `FLEET_GRAFANA_ENV_FILE`, an owner-only env file containing a separate random `GF_SECURITY_ADMIN_PASSWORD`, then explicitly select `--profile research`. It has loopback ports, pinned images, separate volumes, memory limits, dropped capabilities and no-new-privileges. Tempo and Prometheus retain operational projections for 24 hours. Local Tempo storage is for development/evaluation. This assignment does not deploy it.

Runtime projection is opt-in with `FLEET_OBSERVABILITY_OTLP_URL=http://127.0.0.1:PORT/`. Main/worker use a separate bounded pump after SQL commits; no telemetry IO runs in gameplay transactions. Explicit trace/meter providers register no global HTTP/SQL/model instrumentation or environment resource detectors. Only schema-allowlisted trace metadata is emitted; metric dimensions are fixed enums, with 512-series SDK ceilings. Private body text, artifact payloads, provider credentials and arbitrary errors never become telemetry. Operational SQL/byte artifacts remain authoritative independently of OTel.

Delivery uses leased SQL claims, deterministic trace/span IDs, finite three-attempt delivery and visible pending/exported/dropped states. Retries may redeliver identical span IDs after a crash; they never dispatch a model/game call. A failed delivery attempt is counted even when later recovered. Runtime shutdown drains the bounded projection batch. Collector queues/retries only telemetry, and its own metrics are scraped. Dashboards show queues, measured service latency, RSS, byte states, capture-failure census, unknown usage and exporter lag/loss. A run without a capture failure is not automatically complete or qualified: inspect the authenticated frozen coverage manifest for that claim.

Configuration references: [Tempo monolithic evaluation deployment](https://grafana.com/docs/tempo/latest/set-up-for-tracing/setup-tempo/deploy/locally/linux/) and [Collector internal telemetry](https://opentelemetry.io/docs/collector/internal-telemetry/). The actual pinned images, rather than latest documentation alone, are exercised by the fixture.
